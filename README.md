# DineDesk — Restaurant Billing System

A desktop-based restaurant billing and order management application built with **Python and Tkinter**. DineDesk provides a simple interface for managing menu items, creating orders, calculating bills, and tracking sales.

# Features

**Menu Management** — Browse items by category and search the menu
**Order Management** — Add, remove, and manage items in the cart
**Billing** — Automatic subtotal, discount, tax, and final total calculation
**Customer Details** — Capture customer information during checkout
**Sales Tracking** — View basic sales information through the dashboard
**Data Persistence** — Store application data using JSON files
**Desktop GUI** — Clean and interactive Tkinter interface
